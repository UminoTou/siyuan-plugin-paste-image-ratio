# 图片粘贴默认尺寸

[English](https://github.com/UminoTou/siyuan-plugin-paste-image-ratio/blob/main/README.md) | **简体中文**

思源笔记桌面端插件：粘贴图片后，自动按设定的**宽度占比**（可选高度上限）设置图片尺寸，省去每次粘贴后手动调整。

## 功能

- 粘贴图片（剪贴板图片、图片文件、带 `<img>` 的 HTML、思源内部复制）后，自动把新图片宽度设为设定百分比，默认 50%
- 尺寸通过图片自身的样式写入，效果与思源图片右键菜单里的「宽度」一致，随笔记保存，导出 HTML/PDF 时同样生效
- 可设置高度上限（px），开启时图片按原比例等比缩放，不拉伸、不放大
- 已经带宽度/高度样式的图片不会被覆盖；表格单元格内的图片会跳过
- 只处理新粘贴的图片，不会批量改动历史笔记

## 使用

1. 启用插件后，打开任一文档，直接粘贴一张图片
2. 修改尺寸：在 `设置` → `集市` → `已下载` → `插件` 中打开本插件的设置；或在命令面板/快捷键设置中执行命令「打开图片粘贴默认尺寸设置」

设置项：

| 设置 | 说明 |
| --- | --- |
| 粘贴后自动设置图片尺寸 | 总开关，默认开启 |
| 宽度占比（%） | 相对编辑区宽度，取值 1-100，默认 50 |
| 高度上限（px） | 0 表示不限制；大于 0 时等比缩放，小图不会被放大 |
| 输出调试日志 | 默认关闭；开启后向控制台和插件存储目录写日志，排查问题时用 |

## 兼容性

需要思源 3.8.7 及以上（即 `plugin.json` 的 `minAppVersion`）；实测于 3.8.11。

思源 3.8.10 引入了富文本文档标题。标题区域内部现在也挂了一个 protyle-lite 片段，其中带有一个 `.protyle-wysiwyg`，位置在正文编辑区**之前**。1.0.0 用 `protyle.querySelector(".protyle-wysiwyg")` 取编辑区 —— `querySelector` 返回的是文档顺序上的第一个匹配，于是 3.8.10+ 上拿到的是标题里的空编辑器，扫不到任何图片，10 秒后静默退出，看起来像插件没生效。

1.0.1 改为从粘贴事件的目标元素取编辑区（`target.closest(".protyle-wysiwyg")`），不依赖 DOM 顺序。更早的版本没有标题编辑器，同一段查找依然落在正文编辑区上。

## 已知限制

- 宽度会按思源自身缩放的做法减去 8px 行内间隙，因此 20% 一行可放 5 张、50% 一行可放 2 张；单张图宽度会略窄 8px
- 导出的 Markdown 不携带图片尺寸，这是思源自身的 Markdown 导出限制

## 更新日志

### 1.0.1

- 修复：思源 3.8.10+ 上粘贴图片无反应，原因是取到的编辑区是富文本标题里的那个
- 修复：尺寸样式写到 `span[data-type="img"]` 内真正承载尺寸的 span 上，DOM 刷新后不再丢失
- 修复：光标恢复改为从目标块反查编辑区，不再复用可能已被替换的编辑区节点

## 数据与隐私

插件只调用本机内核接口读取图片所在段落的块 DOM 并写回尺寸，设置保存在 `data/storage/petal/siyuan-plugin-paste-image-ratio/settings.json`，不访问网络、不上传任何数据。
